# PICO Spatial Template Projects of Spatial Plugin

This repository provides a set of template projects for quickly bootstrapping different types of PICO Spatial applications.
Each template demonstrates a minimal setup for a specific use case — from simple 2D layouts to fully immersive 3D environments.


## Included Modules

### **MinimalWindowContainerPlanar**

A template project that sets a **Minimalist WindowContainer** with `Form.Planar` as the **default container** at launch.

**Description:**

The **Planar WindowContainer** is a clean, lightweight spatial container optimized for primarily 2D content with optional light 3D elements.

Ideal for:

* Static or decorative models
* Simple animations
* Low-interaction, low-complexity visual content

---

### **MinimalWindowContainerVolumetric**

A template project that sets a **Minimalist WindowContainer** with `Form.Volumetric` as the **default container** at launch.

**Description:**

The **Volumetric WindowContainer** is a balanced spatial container designed for medium-scale 3D content.

Ideal for:

* Interactable 3D objects (gadgets, wearables, or tools)
* Medium-detail models
* Scenarios requiring moderate spatial depth and object exploration

---

### **MinimalStageFull**

A template project that sets a **Minimalist Stage** with `StageStyle.Full` as the **default environment** at launch.

Includes a **skydome** and **image-based lighting (IBL)** for a fully virtual immersive environment.

**Description:**

The **Stage** is a large-scale spatial environment for immersive 3D scenes or room-scale models.

Ideal for:

* Full 3D presentations and storytelling
* Environments requiring spatial tracking and environmental awareness
* Expansive or cinematic visual experiences
