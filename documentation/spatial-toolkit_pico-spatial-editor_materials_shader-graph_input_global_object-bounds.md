Returns the bounding box information of the object in the specified space, including size, minimum coordinates, and maximum coordinates.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1a0c051db8c0439386fe18f2471c8f85~tplv-goo7wpa0wc-image.image)
## Output description

* **size**: The size of the bounding box.
* **min**: The minimum coordinates of the object's bounding box.
* **max**: The maximum coordinates of the object's bounding box.
