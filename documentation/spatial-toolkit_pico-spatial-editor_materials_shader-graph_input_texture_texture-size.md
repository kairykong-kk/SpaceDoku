Get the size of the texture and the texel.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3a3b689712d64b86b6cf0bec702f6069~tplv-goo7wpa0wc-image.image)
## Parameter description

* **Filename**: The image file used as the texture.

## Output description

* **Width**: The width of the texture (pixels).
* **Height**: The height of the texture (pixels).
* **TexelWidth**: The size of a single texel in the U direction in texture coordinates, with a value of 1/**Width**.
* **TexelHeight**: The size of a single texel in the V direction in texture coordinates, with a value of 1/**Height**.
