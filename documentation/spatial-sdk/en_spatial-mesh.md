Spatial meshes enable apps to identify real objects in physical space and convert them into virtual mesh data. You can convert this mesh data into model data in spatial applications.
## Core concepts
### Spatial mesh
Spatial meshes are the capture and reconstruction of information about real objects in space. After the app begins mesh scanning, triangular meshes are gradually generated in areas viewed by the user. Spatial mesh information also includes meshes' bounding boxes, semantic information, and more.

Spatial meshes are primarily used in mixed reality experiences to provide apps with an understanding of the real-world environment. After reconstructing the physical world as spatial meshes, interaction between virtual and real objects can be better implemented. For example, a virtual small ball that collides with a real-world wall can be bounced back. In addition, by integrating depth sensing technology, apps can implement occlusion between virtual objects and real objects.
You can use PICO Spatial SDK to retrieve real-time information about spatial meshes, such as their vertices, indices, and semantics. You can also set different levels of detail (LOD) according to your app's requirements to retrieve meshes with varying levels of granularity. Additionally, you can also use the SDK's built-in mesh rendering component to visualize meshes.
### Mesh anchor
A mesh anchor is an anchor generated by the system after an object is scanned. Mesh anchors contain UUIDs and the data related to mesh models, and are used to describe mesh models recognized in a space.
Mesh anchors cannot be created manually.

### MeshTrackingManager
`MeshTrackingManager` manages and drives mesh anchor data. Mesh anchor data is returned in the callback with `AnchorUpdate` event registered.
## Semantics

## Usage recommendations
It is recommended to use the spatial meshes appropriately for your use case to reduce system overhead. If the app requires complete mesh information of a space, it is recommended to first guide users to look at all areas of the space so that the space can be fully scanned. After generating the corresponding spatial mesh data, let the users continue to experience the remaining content of the app.
If real-time updates to mesh information are not required after creating the Spatial Mesh, it is recommended to store the current mesh data and continue using it, while disabling the Spatial Mesh Provider to reduce resource consumption. In addition, you may consider using a lower LOD to reduce the number of meshes.
## Prerequisites
The app is in Full Space state.
## Code sample
The following code implements dynamic management of mesh anchors: by listening to anchor addition, update, and removal events, the system automatically creates, updates, or destroys the corresponding virtual model entity for each anchor, and keeps their transform synchronized with the anchors' positions and orientations in the physical space.
```Kotlin
MeshTrackingManager.subscribeAnchorUpdate {
    if (it.event == AnchorUpdate.Event.ADDED) {
        // After receiving the Add event, convert the UUID of the mesh anchor into a MeshResource
        val mesh = MeshResource.loadFromMeshAnchor(it.anchor.anchorUUID)
        val material =
            UnlitMaterial.create().apply {
                setBaseColor(Color4.BLACK)
                setPolygonFillMode(PolygonFillMode.LINE)
            }
        // Construct a ModelEntity
        val entity = ModelEntity(mesh, material)
        // Convert the coordinate system based on the SpatialView's root entity node
        val position =
            MRSampleHelper.entity!!.convertPositionFrom(it.anchor.transform.position, null)
        val rotation =
            MRSampleHelper.entity!!.convertRotationFrom(
                it.anchor.transform.rotation.toQuat(),
                null
            )
        entity.components[TransformComponent::class.java]?.apply {
            setPosition(position)
            setQuaternion(rotation)
        }
        // Add the newly created entity to the root node
        MRSampleHelper.entity?.addChild(entity)
        // Manage the new entity via UUID
        MRSampleHelper.entityMap[it.anchor.anchorUUID] = entity
    }
    if (it.event == AnchorUpdate.Event.REMOVED) {
        // Upon receiving the event that a mesh anchor is removed, destroy the entity corresponding to the UUID of that mesh anchor
        if (MRSampleHelper.entityMap.containsKey(it.anchor.anchorUUID)) {
            MRSampleHelper.entityMap[it.anchor.anchorUUID]?.destroy()
            MRSampleHelper.entityMap.remove(it.anchor.anchorUUID)
        }
    }
    if (it.event == AnchorUpdate.Event.UPDATED) {
        // When a mesh anchor update event is received, find the entity corresponding to the UUID of the mesh anchor and update the model's coordinate data
        if (MRSampleHelper.entityMap.containsKey(it.anchor.anchorUUID)) {
            val entity = MRSampleHelper.entityMap[it.anchor.anchorUUID]
            val mesh = MeshResource.loadFromMeshAnchor(it.anchor.anchorUUID)
            entity?.components?.get(ModelComponent::class.java)?.mesh = mesh
            val position =
                MRSampleHelper.entity!!.convertPositionFrom(
                    it.anchor.transform.position,
                    null
                )
            val rotation =
                MRSampleHelper.entity!!.convertRotationFrom(
                    it.anchor.transform.rotation.toQuat(),
                    null
                )
            entity?.components?.get(TransformComponent::class.java)?.apply {
                setPosition(position)
                setQuaternion(rotation)
            }
        }
    }
}
```

Call the `start` function to start updating mesh anchor data.
You need to subscribe to the mesh anchor’s `AnchorUpdate` event before the `start` function can push update data.

```Kotlin
MeshTrackingManager.start()
```

## API reference
The `MeshTrackingManager` and `MeshAnchor` classes provide properties and functions related to spatial meshes. For more information, refer to the [API Reference](https://developer.picoxr.com/spatial-api/index.html).
