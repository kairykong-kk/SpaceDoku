Plane detection is a key environmental perception technology in augmented reality and mixed reality. It enables the system to identify planes in the real world, enabling virtual objects to interact and integrate accurately with the physical environment.
Through plane detection, MR apps can identify and track horizontal, vertical, or inclined surfaces, such as floors, tabletops, walls, and sloped roofs, ensuring that virtual objects are placed accurately and remain stably aligned with the real-world space.

## Core concepts
| **Concept** | **Description** |
| --- | --- |
| Plane anchor | A plane anchor is an anchor generated by the system after a plane is scanned. Plane anchors contain UUIDs and the data related to plane models, and are used to describe plane models recognized in a space. <br> ***Note***: Plane anchors cannot be create manually. |
| PlaneTrackingManager | `PlaneTrackingManager` manages and drives plane anchor data. Plane anchor data is returned in the callback with `AnchorUpdate` event registered. |
## Semantics

## Code sample
The following code implements dynamic management of plane anchors: by listening for anchor addition, update, and removal events, the system automatically creates, updates, or destroys the virtual model entity corresponding to each anchor, and keeps their transforms synchronized with the real-world anchors.
```Kotlin
PlaneTrackingManager.subscribeAnchorUpdate {
    if (it.event == AnchorUpdate.Event.ADDED) {
        // After receiving the Add event, convert the UUID of the plane anchor into a MeshResource
        val mesh = MeshResource.loadFromMeshAnchor(it.anchor.anchorUUID)
        val material =
            UnlitMaterial.create().apply {
                setBaseColor(Color4.BLACK)
                setPolygonFillMode(PolygonFillMode.LINE)
            }
        // Construct a ModelEntity
        val entity = ModelEntity(mesh, material)
        // Convert the coordinate system based on the SpatialView's root entity node
        val position =
            MRSampleHelper.entity!!.convertPositionFrom(it.anchor.transform.position, null)
        val rotation =
            MRSampleHelper.entity!!.convertRotationFrom(
                it.anchor.transform.rotation.toQuat(),
                null
            )
        entity.components[TransformComponent::class.java]?.apply {
            setPosition(position)
            setQuaternion(rotation)
        }
        // Add the newly created entity to the root node 
        MRSampleHelper.entity?.addChild(entity)
        // Manage the new entity via UUID
        MRSampleHelper.entityMap[it.anchor.anchorUUID] = entity
    }
    if (it.event == AnchorUpdate.Event.REMOVED) {
        // Upon receiving the event that a plane anchor has been removed, destroy the entity corresponding to the UUID of that plane anchor
        if (MRSampleHelper.entityMap.containsKey(it.anchor.anchorUUID)) {
            MRSampleHelper.entityMap[it.anchor.anchorUUID]?.destroy()
            MRSampleHelper.entityMap.remove(it.anchor.anchorUUID)
        }
    }
    if (it.event == AnchorUpdate.Event.UPDATED) {
        // Upon receiving the update event for a plane anchor,locate the entity corresponding to the UUID of that plane anchor and update the model's coordinate data
        if (MRSampleHelper.entityMap.containsKey(it.anchor.anchorUUID)) {
            val entity = MRSampleHelper.entityMap[it.anchor.anchorUUID]
            val mesh = MeshResource.loadFromMeshAnchor(it.anchor.anchorUUID)
            entity?.components?.get(ModelComponent::class.java)?.mesh = mesh
            val position =
                MRSampleHelper.entity!!.convertPositionFrom(
                    it.anchor.transform.position,
                    null
                )
            val rotation =
                MRSampleHelper.entity!!.convertRotationFrom(
                    it.anchor.transform.rotation.toQuat(),
                    null
                )
            entity?.components?.get(TransformComponent::class.java)?.apply {
                setPosition(position)
                setQuaternion(rotation)
            }
        }
    }
}
```

Call the `start` function to start updating mesh anchor data.
You need to subscribe to the plane anchor’s `AnchorUpdate` event before the `start` function can push update data.

```Kotlin
PlaneTrackingManager.start()
```

## API reference
The `PlaneTrackingManager` and `PlaneAnchor` classes provide the properties and functions related to plane detection. For more information, refer to the [API Reference](https://developer.picoxr.com/spatial-api/index.html).
