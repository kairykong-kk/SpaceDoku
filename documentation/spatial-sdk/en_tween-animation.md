Tween animation is a technique that automatically interpolates intermediate states between the starting keyframe and the ending keyframe. You only need to define either the start and end values of the property or the amount of change to create smooth animation.
The advantages of tween animation lie in its simplicity and efficiency, making it suitable for simple geometric transformations, position changes, color gradients, material parameter adjustments, and more. For animations that require complex motion, such as multi-part coordination, nonlinear movement, or effects-driven animation, it is recommended to use more flexible animation methods, such as frame-by-frame animation or property animation.

## Implement tween animations
This section uses the above-mentioned example project to walk you through how to programmatically create tween animations and play them.
### Step 1: Create a tween animation
You can use the `TweenAnimation.createTweenAnimation()` function to create a tween animation. When calling this function, you need to specify the animation's bind target, the initial and final values (or the amount of change) of the bind target, and configure other parameters as needed.
#### Specify the bind target
You need to specify the property that the animation changes, that is, the animation's bind target (`bindTarget`). The bind targets supported by the PICO Spatial SDK include position, rotation, scale, transformation, as well as material-related properties of the model, such as color, transparency, metallic, roughness, emission, and normal strength. You can set the bind target for an animation using the static functions in the `AnimationBindTarget` class, such as `AnimationBindTarget.bindPosition()` and more.
If the bind target is the material of a model, you need to specify the index and property name of the material. You can bind a property of a material in the following two ways:

* ***Method 1***: Use `MaterialTarget`
   ```Kotlin
   fun bindMaterial(materialIndex: Int = 0, materialTarget: MaterialTarget): AnimationBindTarget
   ```

   This method is applicable to the following types of materials and models:
   * Materials loaded or created programmatically using the PICO Spatial SDK.
   * Models in USD and glTF formats, such as the `TweenAnimationEntity` of the glb model located at app/src/main/assets/pico_robot_static.usdz in the sample project.
   * AssetBundle generated by Spatial Editor.
   The enumeration type `MaterialTarget` maps its values to system-predefined material property names, for example, `baseColor`, `opacity`, `metallic`, `roughness`, `emissive`, and `normal`.
* ***Method 2***: Directly use the name of the material's property
   ```Kotlin
   fun bindMaterial(materialIndex: Int = 0, materialPropertyName: String): AnimationBindTarget
   ```

   This method is suitable for custom materials. You can also directly use the system-predefined material property names. In this case, method two works the same as method one.

#### Specify the initial and final values (or the amount of change) for the specified property
Tween animations automatically interpolate the transition based on the initial and final values (or the amount of change) of a property. Therefore, you need to specify the initial and final states of the property by setting one or both of the `from`, `to`, or `by` parameters. The PICO Spatial SDK supports the following four configurations.

* Set the `from` and `to` parameters to define the initial and final values; the system will automatically perform a smooth transition.
* Set the `from` and `by` parameters to define the initial value and the amount of change; the system will automatically calculate the final value and perform a smooth transition.
* Only set the `to` parameter to define the final value, the system uses the state before the animation starts as the initial value by default and automatically performs a smooth transition.
* Only set the `by` parameter to define the amount of change. The system uses the state before the animation starts as the initial value by default, automatically calculates the final value, and performs a smooth transition.

For different `bindTarget` and `materialTarget`/`materialPropertyName`, the values of the `from`, `to`, and `by` parameters will also be of different types:
| **`bindTarget`** | **`materialPropertyName`** | **Parameter types for** **`from`, `to`, and `by`** |
| --- | --- | --- |
| `bindPosition()` | / | `Vector3` |
| `bindRotation()` | / | `Rotator` |
| `bindScale()` | / | `Vector3` |
| `bindTransform()` | / | `Transform` |
| `bindMaterial` | `baseColor` | `LinearColor` |
| `bindMaterial` | `opacity` | `Float` |
| `bindMaterial` | `metallic` | `Float` |
| `bindMaterial` | `roughness` | `Float` |
| `bindMaterial` | `emissive` | `LinearColor` |
| `bindMaterial` | `normal` | `Float` |
#### Configure other parameters
In addition to the required parameters mentioned above, you can also configure other parameters when creating a tween animation to implement specific effects. For example, you can use the `duration` and `speed` parameters to modify the playback speed, use the `repeatCount` and `repeatMode` parameters to specify the number of repetitions and the repeat mode (replay or reverse), or use the `easeType` parameter to adjust smooth transition, and more.
### Step 2: Generate animation resources
You can use the `AnimationResource.generateWithTweenAnimation()` static function to generate a tween animation resource.
```Kotlin
tweenAnimationResource = AnimationResource.generateWithTweenAnimation(tweenAnimation)
```

### Step 3: Play the tween animation
When creating a tween animation, you have already bound the target, that is, the property of a certain entity instance that you want to change. When playing an animation, you need to use the `entity.playAnimation(tweenAnimationResource)` function of the target entity instance.
For example, in the sample project, if you want to change the overall position of a `TweenAnimationEntity` instance, and the target entity instance is `this`. You can use `this.playAnimation(tweenAnimationResource!!)` to play an animation. If you want to change the material of a `TweenAnimationEntity` instance, you must first locate the node in the entity hierarchy that is bound to the material, and then play the animation through this node. PICO Spatial SDK provides the `entity.findEntity("name")` function, which is used to find a node by name within the entity hierarchy. Therefore, if you know the node name of the mesh where the material is located, you can use `this.findEntity("name")!!.playAnimation(tweenAnimationResource!!)` to play the animation.
In the sample project, during initialization, we found the node `body` of the mesh containing the material (whose name is `geo_body`).
```Kotlin
private suspend fun initialize() {
    val character = withContext(Dispatchers.IO) { load(STATIC_ROBOT) }
    addChild(character)
    // Set initial transform
    body = character.findEntity(NODE_BODY)
    // Record initial material
}

companion object {
    // ...
    private const val NODE_BODY = "geo_body"
    // ...
}
```

If your model contains other nodes with the same name as the target node, it is recommended to use Blender or other DCC software to modify the name of the target node or the other nodes, so as to make the result of node search unique.

After locating the node of the mesh containing the material, you can play the material animation using the following code:
```Kotlin
body?.let {
    // For animations that change transparency, you must set BlendingMode to TRANSPARENT first
    if (isOpacityAnimation) {
        pbrMaterial!!.setBlendingMode(BlendingMode.TRANSPARENT)
    }
    it.playAnimation(tweenAnimationResource!!)
}
```

For the complete code for creating a tween animation, generating animation resources, and playing the tween animation, refer to the `playTweenAnimation` function in the TweenAnimationEntity.kt file.
### Step 4: Stop playback & release animation resources
Like other resources, tween animation resources must be manually released after use. In the sample project, each time you switch to a new tween animation, the `reset()` function is called. This function stops playing all animations, resets the transform and material, and releases animation resources:
```Kotlin
fun reset() {
    this.stopAllAnimations()
    // Reset transform...
    // Reset material...
    tweenAnimationResource?.close()
    tweenAnimationResource = null
}
```
