## Parameter description
The following describes the meaning of each parameter:

* **Left**: The value returned when viewing the texture through the left eye in stereoscopic rendering.
* **Right**: The value returned when viewing the texture through the right eye in stereoscopic rendering.
* **Mono**: The value returned when using a single renderer.
