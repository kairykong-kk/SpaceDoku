Rotate a 3-vector around a specified unit axis vector.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f7925cbe1d25407caee4cd2f3e90df9d~tplv-goo7wpa0wc-image.image)
## **Parameter description**

* **In**: The vector to be rotated.
* **Amount**: The rotation angle of the Input vector, in degrees; the default value is `0`.
* **Axis**: The unit axis vector used for rotation; the default value is `(0, 1, 0)`.
