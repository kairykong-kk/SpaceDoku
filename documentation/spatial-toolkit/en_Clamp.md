Restricts the input to the range between **Low** and **High** for each channel.
If **In** is within this range, the output value is the same as **In**; otherwise, the output value is limited to the nearest boundary, that is, **Low** or **High**.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c0ac5e0ba150486696cf10baa3e09c2f~tplv-goo7wpa0wc-image.image)
## **Parameter description**

* **In**: The input value to be restricted.
* **Low**: The lower bound of the restriction range.
* **High**: The upper bound of the restriction range.
