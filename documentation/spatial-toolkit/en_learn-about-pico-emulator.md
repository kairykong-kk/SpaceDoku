PICO Emulator is a tool that simulates the PICO OS environment on a PC. You can debug spatial apps in PICO Emulator.
PICO Emulator supports the following features:

* Install spatial apps packaged as .apk files.
* Push .obb files or .bundle files to installed spatial apps.
* Simulate eye-hand interaction or controller interaction.
* Map PC keyboard keys to corresponding controller buttons using controller button mode.
* Support UI debugging, including performance data mode, bounding box mode, collider mode, and axis mode.
* Support MR simulation features, including Video Seethrough (VST) simulation and Spatial Mesh simulation.
