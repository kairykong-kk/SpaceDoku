## Node usage instructions
This value continuously changes, so after connecting it to other nodes, it can be used to create dynamic material effects.
After adding Time to the horizontal component of the Input texture coordinates, the texture will scroll horizontally. The following node graph example demonstrates how to make an image texture scroll in real time:
