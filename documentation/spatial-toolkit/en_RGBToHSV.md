Convert colors from the RGB color space to the HSV color space.

## Parameter description

* **In**: Input a standard RGB-formatted color.
* **Out**: Output a color vector containing hue (Hue), saturation (Saturation), and value (Value).

## Node usage instructions
This node performs a standard color space conversion algorithm, converting RGB values in Cartesian coordinates to HSV values in cylindrical coordinates, making it easier to make intuitive color adjustments, such as modifying hue or saturation independently.
