This article introduces the UI displayed after launching the PICO Emulator.
The PICO Emulator UI consists of the main display area, the tool area in the upper left corner, and the operation area in the lower right corner.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3d0e9fed21464e91aa73454f3042da10~tplv-goo7wpa0wc-image.image)
## Main display area
The main display area shows the right-eye screen of the PICO device after startup. In this area, you can use a mouse and keyboard to simulate native XR interactions on the PICO device.
### Shortcuts
You can interact with the virtual scene in the main display area using the following shortcuts:
| **Action** | **Purpose** |
| --- | --- |
| Click the left mouse button | Interact with objects by left-clicking, commonly used for confirming button clicks. |
| Press and drag the right mouse button | Control the rotation of the viewpoint. |
| Scroll the mouse wheel | Control the viewpoint to move forward or backward. |
| Press the W key (or up arrow) on the keyboard | Move the viewpoint forward. |
| Press the S key (or down arrow) on the keyboard | Move the viewpoint backward. |
| Press the A key (or left arrow) on the keyboard | Move the viewpoint to the left. |
| Press the D key (or right arrow) on the keyboard | Move the viewpoint to the right. |
| Press the Q key on the keyboard | Move the viewpoint downward. |
| Press the E key on the keyboard | Move the viewpoint upward. |
| Use the shortcut Ctrl + R (command + R on macOS) | Restore the viewpoint to its initial position and orientation. |
### Virtual MR background
You can see a virtual MR background with a bedroom scene in the main display area. This is because the PICO Emulator supports MR simulation features, including Video See-Through (VST) simulation and Spatial Mesh simulation.
#### Video See-Through (VST) simulation
Video See-Through (VST) simulation is enabled by default and uses the built-in "bedroom" scene as the virtual MR background.
Video See-Through (VST) technology can break the fully enclosed virtual environment provided by VR headsets. It uses cameras on the headset to capture real-time views of the surrounding environment, then presents the real scene on the headset screen through image processing algorithms, allowing users to browse the real environment directly on the headset screen. Ultimately, the see-through view can be merged with the virtual scene in the application to present a mixed reality effect. The Video See-Through (VST) view is processed directly by the PICO system and displayed on the screen; applications cannot access any physical environment information of the user.
#### Spatial Mesh simulation
Spatial Mesh simulation provides spatial mesh data for the virtual scene.
Spatial Mesh captures and reconstructs information about real objects in the space. After the application starts mesh scanning, triangular meshes are gradually generated in places the user has viewed. Spatial mesh data also includes mesh bounding boxes, semantics, and other information.
You can use the PICO Spatial SDK to obtain spatial mesh vertices, indices, semantics, and other information in real time, and set different levels of detail (LOD) according to application requirements to obtain meshes with varying granularity. In addition, you can also use the mesh rendering component built into the SDK to visualize the mesh. For details, see [Spatial Mesh](/document/spatial-sdk/spatial-mesh/).

| Debugging | Used to set the theme mode, display language, screen FOV, and UI debug mode. <br>  <br> * **Screen FOV**: The FoV of the virtual camera in the PICO Emulator window. The range is 70° to 95°.
