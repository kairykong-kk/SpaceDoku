Obtain the size of the texture and texel.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3a3b689712d64b86b6cf0bec702f6069~tplv-goo7wpa0wc-image.image)
## Parameter description

* **Filename**: Image file used as the texture.

## Output description

* **Width**: Width of the texture (pixels).
* **Height**: Height of the texture (pixels).
* **TexelWidth**: Texture coordinate size of a single texel in the U direction, with a value of 1/**Width**.
* **TexelHeight**: Texture coordinate size of a single texel in the V direction, with a value of 1/**Height**.
