PICO Spatial Editor is a 3D scene composition tool. Spatial Editor supports the following features:

* **Scene management**: Build complex 3D scenes flexibly by combining resources such as mesh, material, texture, and audio, without writing any code.
* **Connect spatial apps**: Import Spatial Editor projects into spatial projects to provide scene support for your spatial app.
* **Custom shaders**: Create custom shaders using Shader Graph in Spatial Editor.
* **Animation effects**: Create animations using Timelines in Spatial Editor.
