This article describes how to install PICO Emulator in your Android Studio.
## Environment requirements
### Operating system and hardware requirements
To use PICO Emulator, your operating system and hardware must meet the following minimum requirements.
To ensure smooth emulator operation, it is recommended to reserve at least 12 GB of available memory.

| **Operating system** | **Requirements** |
| --- | --- |
| macOS <br>  <br>  | * **Operating system version**: macOS 14.0 <br> * **RAM**: 16 GB <br> * **Available disk space**: 32 GB <br> * **CPU**: M1 Pro, Intel chips are not supported |
| Windows | * **Operating system version**: Windows 10 64-bit or Windows 11 64-bit <br> * **RAM**: 16 GB <br> * **Available disk space**: 32 GB <br> * **CPU**: Intel Core i5 <br> * **GPU**: NVIDIA GeForce GTX 1060, video memory not less than 8 GB |
### Software requirements
You have already installed the PICO Spatial Plugin. For details, see [Install PICO Spatial Plugin](/install-spatial-plugin).
## Steps
### Step 1: Install PICO Emulator via PICO Spatial Plugin
Install PICO Emulator through the PICO Spatial Plugin in Android Studio. For details, see [Manage spatial app development tools](/manage-pico-toolbox).
### Step 2: Add PICO Emulator in Android Studio
Open a spatial project in Android Studio, in **Device Manager**, click the plus sign and select **Create PICO Emulator**.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/41e3d1b16e3f4d5e9a2b49060f7c4902~tplv-goo7wpa0wc-image.image)
### Step 3: Run PICO Emulator
After PICO Emulator is added to Android Studio, you can click the launch button on the right to start PICO Emulator.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3de18968f23c47928eaedf535f1bc517~tplv-goo7wpa0wc-image.image)
