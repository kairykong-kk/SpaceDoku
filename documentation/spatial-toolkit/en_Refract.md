Calculate the refraction result of the Input vector based on the given surface normal and refractive index (eta).

## **Parameter description**
Vectors passed to the **In** and **Normal** parameters must be normalized in advance.


* **In**: The vector to be refracted.
* **Normal**: The surface normal where the Input vector is refracted.
* **Eta**: The refractive index.
