Each Dot in Page Control represents a page in the parallel list. Users can customize the number of displayed Dots. In principle, there is no restriction on the actual number of pages. If the actual number of pages exceeds the number of displayed Dots, the excess pages on either side are indicated using an ellipsis style (two consecutive smaller dots).

2. Omitted dot: Indicates that the actual number of pages is greater than the number of pages displayed

## Interactive behavior
### Turn page
Users can turn pages by clicking or swiping left or right. Clicking any non-ellipsis Dot allows you to navigate directly to a specific page, while clicking an ellipsis Dot displays the next or previous page.
### Auto carousel
Page Control supports carousel paging, with the carousel duration customizable by the developer. After directly interacting with Page Control, the carousel stops; if the content is an animated image or video, it stops at the last frame. Resume the carousel after switching page content by sliding.
