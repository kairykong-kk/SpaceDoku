A checkbox is an interactive component in the user interface used to enable selection. Users can select or deselect it by clicking, and when selected, a checkmark (such as ✓ or —) appears inside the box. Its core functionality allows users to select one or more options from a set, including selecting all or deselecting all, and is suitable for situations where multiple selections are allowed.

## Anatomy
A Checkbox can be used individually to allow users to confirm a specific action, such as "Do not show again," or in combination to present multiple items to users.

1. **Visual container:** Styled as a circle, it typically conveys "selected", "unselected", or "partially selected" states intuitively through state changes.
2. **Label text:**
   Position: Immediately adjacent to the visual container (usually on the right side, in some cases on the left side, and must follow unified interface standards).

### Dimensions
Available in two sizes: Small and Default. Both hot zone sizes are 32 × 32 dp; only the display size differs.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1e2c2aefe0e243c895d65f8160af31b9~tplv-goo7wpa0wc-image.image)
## Interactive behavior
**State switching:**

* Unselected: empty circle
* Selected: a solid circle with a check mark is displayed
* Partially selected: solid circle and box with a horizontal line `—` (used for the intermediate state in hierarchical selection)
