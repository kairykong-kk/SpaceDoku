PICO officially provides the following six fonts, five of which support continuously variable weight and width, offering greater flexibility for multilingual adaptation, typesetting, and quality enhancement. Font files are built into PICO OS 6, allowing developers to access them directly in their applications.
The scope of font usage authorization is limited to products running on the PICO platform. Developers must not use this font file or any derivative versions for projects unrelated to the PICO platform, nor transfer or sublicense it to other organizations.


* **PICO Sans**
   Contains 324 characters and supports display in English, German, French, Dutch, Spanish, Finnish, and other languages. In addition, the font also supports continuous weight (from 100 to 900) and continuous width (from 60% to 100% to 500%) for display. How to set variable font width in Android: *`android:fontVariationSettings="'wdth' 70"`* *or* *`textView.setFontVariationSettings("'wdth' 70")`*`;`
