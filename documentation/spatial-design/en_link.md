The Link has its basic style characteristics. Link-style text buttons are less visually prominent than regular buttons. Due to its relatively unobtrusive nature, it is typically used as an interaction method for optional operations in practical operation design, allowing users to independently choose whether to perform the related operations according to their own needs.

## Anatomy
### Content
Link-style text buttons can be divided into pure text form or text-and-icon form. Clicking will open the content in a browser for viewing. This is commonly used for statements, explanations, and similar content.

## Interactive behavior
Link-style text buttons have three interaction states:

1. Normal state: The default appearance of a link-style text button when there is no user interaction and no special circumstances.
2. Hover state: When the cursor is placed over a link button using hand pose, controller, or head control, the button enters the hover state. A background fill appears beneath the text to indicate to the user that the element is clickable.
3. Pressed state: When the button is pressed, a click event is triggered, and the button's background color changes.
4. Disable (unavailable state): The button is currently disabled and appears grayed out, so the user cannot interact with it.
