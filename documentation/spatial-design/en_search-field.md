## Search box
The search box is primarily used to help users quickly locate desired content within large volumes of information, and can significantly improve users' efficiency in obtaining information. Typically displays the "Search" button, "Voice" button, "Clear" button, and optional placeholder text.

* When real-time search cannot be performed due to business constraints, trigger the search using the "Button" on the right.
* Recommended content will be displayed when the input box receives focus.

### Copy length

* When performing input operations, if the input text is found to be too long, the method of omitting the earlier part of the content will be adopted to ensure input efficiency and facilitate processing. In this way, you can focus more on the key information at hand and avoid unnecessary redundancy and confusion during operation caused by excessively long preceding content.
* When performing a search, if the input text is excessively long, the system will automatically omit the subsequent part of the text to ensure efficient searching and a streamlined interface.
