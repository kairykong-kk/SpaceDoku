In the eye, hand, and body sensing interaction mode, PICO introduces global gestures, which enable users to quickly invoke system functions in any usage scenario.

* Instructions: Look at your palm to bring up the home button icon, then pinch with your index finger and thumb to trigger the system function. After invoking the Home key, the triggering of system gestures depends on the duration of the pinch and activates two different states.

* Status descriptions
   * When the index finger and thumb are quickly pinched together and released, the resource library can be accessed rapidly.
   * After pinching for a period of time, the home key expands to display the system gesture menu, which includes three functions. The user can maintain the pinch gesture with the index finger and thumb and move the gesture in space. After selecting the desired function, releasing the gesture will activate the corresponding function. The menu includes the following features:
      * Control Center: Used to adjust settings within the system, such as volume, safety boundaries, and so on.
      * App library: Used to view all apps installed on the current system.
      * Dock: Used to view other currently running apps and quickly launch apps.

To bring up the system gesture menu, the relative position of the hand and head must be at a physiologically appropriate angle; otherwise, the Home button cannot be activated properly. If the user wants to cancel a selection after invoking the system gesture menu, they can move their hand toward an area away from the gesture menu until the menu gradually disappears.
## **Suggestions**
Compatibility with system gestures: You need to avoid conflicts between custom in-app interaction gestures and system gestures to prevent affecting the in-app experience or interfering with users quickly accessing system functions. Meanwhile, when system gestures are activated, the content within the application should pause or remain static to ensure that the user experience remains seamless when users return to the application after using system gestures.
