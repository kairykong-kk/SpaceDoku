Spatial UI is the spatial app development framework that PICO OS 6 primarily supports. It provides a declarative development experience. Its main features are as follows:

* Android developer-friendly, compatible with the Android ecosystem
* Declarative UI
* 2D/3D integration
* Supports for multi-window and multiple app modes
* Supports multi-modal interactions:
   * Far-field: eye and hand tracking, controller
   * Near-field: bare hand touch, controller
   * Peripherals: mouse, keyboard, and more

Based on the brand style of PICO Design, Spatial UI offers a wide range of themes and components to help you create a user interface for your app that delivers a consistent experience and a distinctive brand identity.
## Theme
The Spatial UI component library provides a set of themes (PicoTheme) featuring the PICO brand style, which includes four categories of configuration: color, text layout, general, and system material. These configurations define the appearance of spatial apps and influence the default behavior of each component. For example:

## Component
Components are modular units used for flexibly building a complete spatial app. The Spatial UI component library provides a series of high-quality, configurable components based on the PICO Design, such as Button, TextField, and ToolBar. By using these UI components, you can integrate traditional 2D content and interactions into your app.
