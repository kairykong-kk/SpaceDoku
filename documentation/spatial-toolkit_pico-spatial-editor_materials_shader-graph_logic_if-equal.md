Output different results based on whether **Value1** is equal to **Value2**: if they are equal, output **True Result**; otherwise, output **False Result**.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/61adefcb1ab94fd0b414919e20a63bb3~tplv-goo7wpa0wc-image.image)
## Parameter description

* **Value1**: The first value to compare.
* **Value2**: The second value to compare.
* **True Result**: The result output when **Value1** is equal to **Value2**.
* **False Result**: The result output when **Value1** is not equal to **Value2**.
