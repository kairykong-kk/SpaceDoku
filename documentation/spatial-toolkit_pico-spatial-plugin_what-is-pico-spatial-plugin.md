PICO Spatial Plugin is an all-in-one spatial app development plugin based on Android Studio, providing developers with a complete spatial app development toolchain.
PICO Spatial Plugin supports the following features:

* **Spatial app templates**: Provides spatial app templates in Android Studio. You can quickly create spatial projects based on the templates. See [Manage spatial projects](/manage-projects) for details.
* **Build spatial projects**: Build spatial projects into spatial apps. See [Manage spatial projects](/manage-projects) for details.
* **Manage spatial app development tools**: Install, upgrade, or uninstall PICO Emulator (emulator) and PICO Spatial Editor (Spatial Editor). See [Manage spatial app development tools](/manage-pico-toolbox) for details.
* **Connect spatial apps to Spatial Editor**: You can import Spatial Editor projects into spatial projects to manage 3D assets and custom components synchronously in both Android Studio and Spatial Editor. See [Manage spatial projects](/manage-projects), [Manage assets](/manage-resource), and [Manage custom components](/use-custom-components) for details.
