This document includes release information for PICO Spatial Editor (Spatial Editor).
## 0.11.x
### New features

* New components have been added: DrawOrderGroup, AudioResource, AudioResourceGroup, and HoverEffect. For details, see [General components](/general-components) and [Audio components](/audio-components).
* Image 2D node, Image 2D LOD node, and Node Group have been added to Shader Graph. For details, see [Shader Graph node overview](/shader-graph-node-overview).

### Optimizations

* New parameters have been added to the Particle component, and existing parameters have been optimized.
* Starting from version 0.11.x, Audio Mix Groups created in Spatial Editor can be loaded into PICO Spatial SDK version 0.11.x. For details, see [Use audio mix groups](/use-audio-mixer-group).
* A display toggle for **Bounding Box** has been added to **Gizmo Setting**. **Position** and **Rotation** parameters have been added to the **Camera Preset** in the viewport. For details, see [Manage view](/manage-view).
