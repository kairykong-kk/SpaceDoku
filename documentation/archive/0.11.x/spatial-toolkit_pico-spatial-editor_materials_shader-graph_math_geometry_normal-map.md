Convert normal vectors from object space or tangent space to world space.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/aae7b1ec15cb4ef080307e512981c2b4~tplv-goo7wpa0wc-image.image)
## **Parameter description**

* **In**: The Input vector to be converted; the default value is `(0.5, 0.5, 1.0)`.
* **Space**: Specifies the source space of the normal vector. Optional values are **object** or **tangent**; the default value is **tangent**.
* **Scale**: The scaling factor applied to the Input vector before conversion; the default value is **1.0**.
* **Normal**: The surface normal vector; the default value is the surface normal in the current world space.
* **Tangent**: The surface tangent vector; the default value is the tangent vector in the current world space.
