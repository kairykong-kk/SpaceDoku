This document includes release information for the PICO Spatial Plugin.
## 0.11.x
### New features

* By configuring the parameters of the Spatial Tools plugin, you can perform incremental packaging of Spatial Editor projects at the .bundle file level and select specific files for packaging as needed. See [Manage spatial projects](/manage-projects) for details.
* You can create library modules that include Spatial Editor projects in standard Android projects and select the corresponding minimum PICO OS 6 version, including PICO Spatial SDK and Android API.

### Changes
.usdz files are only supported for preview in Android Studio and can no longer be opened in PICO Spatial Editor using the **Open In Editor** button. Limitation
Only .usda files can be opened in PICO Spatial Editor using the **Open In Editor** button.
