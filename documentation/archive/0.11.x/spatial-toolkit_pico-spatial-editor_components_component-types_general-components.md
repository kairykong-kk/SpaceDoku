This article introduces the general components in Spatial Editor.
General components can be added to or removed from entities. In .usda files, the type of general component is `SpatialComponent`. This is a component type defined by Spatial Editor and is not native to USD.

### Emitter
Emitter settings.
| **Module** | **Parameter** | **Note** |
| --- | --- | --- |
| None | Auto Play | Controls whether particles are emitted automatically. Enabled by default. |
| None | Is Emitting | Controls whether particles are emitted. The default value is Yes. |
| Timing | Loop | Controls whether particles are emitted in a loop. The default value is Yes. |
|  | Emission Duration | The duration of particle emission, in seconds. <br>  <br> * **Random Between Two Constants**: Indicates that the duration of particle emission is randomly selected between two constant values. <br> * **Constant**: (default) Indicates that the duration of particle emission is a fixed constant value. The default value is 1. |
|  | Idle Duration | Sets the interval between each particle emission, in seconds. <br>  <br> * **Random Between Two Constants**: Indicates that the interval between each particle emission is randomly selected between two constant values. <br> * **Constant**: (default) Indicates that the interval between each particle emission is a fixed constant value. The default value is 0. |
|  | Warmup Duration | The warmup time for particle emission, in seconds. The default value is 0. |
| Shape | Shape Type | Available emitter shapes include: <br>  <br> * **Point**: Emits particles from a single point, which has no volume or shape. <br> * **Sphere**: A sphere with a radius of 1 meter, with the origin at the center of the sphere. <br> * **Plane**: (default) A square plane with a side length of 2 meters, with the origin at the center of the plane. <br> * **Box**: A cube with a side length of 2 meters, with the origin at the center of the cube. <br> * **Cylinder**: A cylinder with a base radius of 1 meter and a height of 2 meters, with the origin at the midpoint of its axis. <br> * **Cone**: A cone with a base radius of 1 meter and a height of 2 meters, with the origin located at the midpoint of its axis. <br> * **Torus**: A torus. Its major radius (the distance from the center of the torus to the center of the tube) is 1 meter, and the minor radius (the radius of the tube itself) is defined by the **Torus Inner Radius** parameter. The origin is located at the center of the torus. |
|  | Radial Amount | The quantity in the radial direction. Cannot exceed 360. This parameter can be used to control the number of elements distributed radially in the relevant geometries (Sphere, Torus, Cylinder, Cone). |
|  | Torus Inner Radius | The radius of the torus tube itself (in meters). This parameter, together with the major radius, determines the specific shape and size of the torus. |
|  | Birth Location | Set the position where particles are generated: <br>  <br> * **Surface**: (default) Generated on the surface of the emitter. <br> * **Volume**: Generated inside the emitter. <br> * **Vertices**: Generated at the vertices of the emitter. |
|  | Birth Direction | Set the calculation method for the emission direction of particles: <br>  <br> * **Normal**: (default) Emitted along the normal direction of the emitter's shape. <br> * **World**: Emitted along the direction of the world coordinate system. <br> * **Local**: Emitted along the direction of the entity's own local coordinate system. This direction changes as the entity rotates. |
|  | Shape Size | Set the size of the emitter, in meters. The default value is (0.1, 0.1, 0.1). |

By generating irregular disturbances, it makes the movement of particles exhibit more realistic natural characteristics, such as drifting smoke, flickering flames, and other non-uniform, irregular dynamic effects. |
|  | Noise Strength | Set the strength of the noise force field. The larger the value, the stronger the random disturbance effect of the noise on the movement of particles, and the more pronounced the irregularity of the particles' trajectories. The default value is 0. |
|  | Noise Scale | Set the scaling factor for the noise. The default value is 1. |
|  | Noise Animation Speed | Set the playback speed of the noise animation. The default value is 0. |
|  | Noise Seed | Set the random seed used to generate the noise. Different seeds will produce different random effects. The default value is 0. |
|  | Noise Frequency | Set the frequency of the noise. The default value is 1. |
| Point <br> Attractor <br>  | Enable Point Attractor | Control whether to enable the attractor force field module. Disabled by default. <br> The attractor force field module is used to simulate the effect of gravitational attraction. By setting the attraction center and strength, particles in the particle system are subjected to a pulling force directed toward the center, enabling centripetal motion effects similar to gravity or magnetic attraction. |
|  | Attractor Center <br>  | Set the center position of the attractor force field. The default value is (0, 1, 0). Its coordinate system is determined by the **Description Space** parameter. |
|  | Attractor Strength | Set the strength that attracts particles to the center of the attractor force field. The default value is 0. |
| Vortex <br>  | Enable Vortex | Control whether to enable the vortex force field module. Disabled by default. <br> The vortex force field module is used to simulate vortex motion effects. By setting the direction and strength of the central axis, particles in the particle system rotate around the specified axis, enabling dynamic effects with rotational aggregation characteristics, such as water vortices or tornadoes. |
|  | Vortex Direction | Set the direction of the vortex's central axis. The default value is (0, 1, 0). Its coordinate system is determined by the **Description Space** parameter. |
|  | Vortex Strength | Set the strength of the vortex force field. The default value is 0. |
|  | Vortex In Flow | Control the strength of particles converging toward the vortex center. <br>  <br> * **0** (default value): Particles only rotate around the center and do not converge inward. <br> * **Greater than 0 and less than 1**: Particles rotate while converging toward the center. The larger the value, the faster the convergence speed. <br> * **1**: Particles converge directly to the vortex center along a straight line. |
| Camera Fade | Enable Camera Fade | Controls whether to enable the camera fade effect. Disabled by default. |
|  | Near Distance | Set the near distance for camera fade, in meters. The fade range is from **Near Distance** to **Far Distance**. |
|  | Far Distance | Set the far distance for camera fade, in meters. The fade range is from **Near Distance** to **Far Distance**. |

## Draw Order
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/575eafb37e88400b86bbf7deedbb4186~tplv-goo7wpa0wc-image.image)
This component is used to precisely control the rendering order of entities.
In complex 3D scenes, when multiple **semi-transparent** objects overlap or when the foreground and background occlusion relationships need to be clearly defined, depth sorting conflicts (Z-fighting) may occur, resulting in rendering effects that do not meet expectations. You can control the rendering order of entities through the Draw Order component.
| **Parameter** | **Note** |
| --- | --- |
| Group | Draw Order Group. All entities with the same **Group** belong to one Draw Order Group. You can add one or more Draw Order Groups in the Inspector window. For details, see [Adjust the rendering order of entities within a draw order group](/editor/general-components). |
### Adjust the rendering order of entities within a draw order group
Follow the steps below to add a draw order group, associate it with the entity's Draw Order component, and then adjust the rendering order of entities within the draw order group.
Suppose the scene includes a semi-transparent green sphere and a semi-transparent red plane. By default, the red plane will occlude the part of the green sphere located behind it.
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ddb9e44b38424106b832442f555dc537~tplv-goo7wpa0wc-image.image" width="582px" /></div>


1. In the **Hierarchy** window, click the **+** button, and select **Draw Order Group** from the dropdown menu to create a draw order group.
   ![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a334677c300a41309c4f97035333cc13~tplv-goo7wpa0wc-image.image)
2. Associate entities with a Draw Order Group. You can use any of the following methods:
   * Select the Draw Order Group in the Hierarchy window**, then** drag the entities that need to be associated with the Draw Order Group from the **Hierarchy** window to the Draw Order Group in the **Inspector** window.
      ![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/262a2e8a392e443fafacb287395e5915~tplv-goo7wpa0wc-image.image)
   * Select the entity to associate with the draw order group, locate the **Draw Order** component in the **Inspector** window, click the selection button next to the **Group** parameter, and then choose the newly created draw order group from the list.
      ![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/34234a3be367426786cda123da2a2b5d~tplv-goo7wpa0wc-image.image)
3. Select the draw order group in the **Hierarchy** window, and adjust the rendering order of entities by dragging them in the **Inspector** window. Entities listed higher in the list have a higher rendering priority and will be rendered before those lower in the list.
   ![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/68900163cd4f4892aafbd73e188abffa~tplv-goo7wpa0wc-image.image)

For example, if the green sphere has a higher rendering priority, it will be drawn above the red plane, regardless of their actual spatial relationship. Although the red plane is physically closer to the camera, the green sphere will be rendered in front of the red plane.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/84f80ffbc7a444a7a895b1fdfd078efc~tplv-goo7wpa0wc-image.image)
