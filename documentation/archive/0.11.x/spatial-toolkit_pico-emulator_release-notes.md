This document includes release information for PICO Emulator.
## 0.11.x
### New features

* The UI debugging feature now supports container clipping, plane detection, Spatial Mesh, and Spatial Anchor. For details, see [UI debugging](/ui-debug).
   ![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/084a6eb780244ef4abd54314bd0b8289~tplv-goo7wpa0wc-image.image)

### Improvements

* Screenshot feature improvements: After taking a screenshot, a floating preview window will appear in the lower right corner of the emulator. You can quickly delete screenshots or locate screenshot files through this window, and you can access more features such as "**Save as**" via the right-click menu.
   ![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4b94cac239f14ab1947495383a2833db~tplv-goo7wpa0wc-image.image)
* Screen recording feature improvements: You can set whether to display the mouse pointer in the recording.
   ![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/709a4e0d00114db98f063e3561b6404e~tplv-goo7wpa0wc-image.image)

### Bug fixes

* Fixed an issue where, in certain scenarios, launching PICO Emulator from Android Studio for the first time and attempting to install an application could result in installation failure.
* Fixed an issue where noise could occur during audio playback.
