Spatial UI includes themes and components. The theme defines the visual style of Spatial Apps and also affects the default behavior of each component. Components are used to flexibly build a complete spatial application.

* For information about the topic, see [Theme](/en_theme).
* For information about components, see:

| **Component name** | **Description** |
| --- | --- |
| [Button](/en_button) | Button is used to respond to user clicks. |
| [IconButton](/en_icon-button) | IconButton is a control used to respond to user click interactions. Unlike the Button, the content area of IconButton is typically filled with an `Icon` (it can also be filled with `Text`), while the content area of Button is usually filled with `Text`. |
| [ToggleButton](/en_toggle-button) | ToggleButton is a control with a secondary state that responds to user clicks. Its content area typically contains `Text` or other composable elements. It is commonly used in scenarios such as creating or adding, and supports configuring leading and trailing icons. |
| [ToggleIconButton](/en_toggle-icon-button) | ToggleIconButton is a control with a secondary state that responds to user click interactions. Its content area typically contains an Icon component or other composable elements. |
| [Link](/en_link) | Link is a control without a background or border that responds to user clicks. Its content area is typically text `Text` or other composable items, and it is commonly used for navigation links, learning more, viewing details, and similar scenarios. |
| [Divider](/en_divider) | * The Divider is a component used to divide interface areas, and its appearance is typically that of a linear component. <br> * HorizontalDivider is a component defined by the PICO design guidelines, specifically used to divide interface areas horizontally. <br> * VerticalDivider is a component in the PICO design guidelines that is specifically used to divide interface areas vertically. |
| [Chip](/en_chip) | Chip is a control commonly used in label display scenarios. Depending on style and functionality, it includes ButtonChip, ToggleableChip, and RemoveableChip. |
| [Badge](/en_badge) | * A badge is typically used to display indicators of dynamic information. It can be overlaid on other components as a small icon or number to notify users. <br> * DotBadge is used as a dot indicator, typically for simple message notifications. <br> * NumberBadge is used to display numbers. |
| [CheckBox](/en_check-box) | * CheckBox is a basic control that allows users to select one or more options from a list. <br> * TriStateCheckbox is a checkbox with three states, suitable for scenarios such as all selected, none selected, or partially selected. |
| [Switch](/en_switch) | Switch is a basic control used to toggle between two states. It can be used to turn a setting on or off, enable or disable a feature, select an option, and many other scenarios. |
| [Option](/en_option) | Option is a basic component with a "selected" state. You can combine multiple Option to freely implement "multi-select" and "single-select" scenarios. |
| [Slider](/en_slider) | * Slider allows users to set attribute values by dragging, in scenarios such as adjusting screen brightness, volume, and similar situations. <br> * SegmentSlider is a segmented slider that allows users to set attribute values by dragging. It can be used in step-by-step processes or scenarios with multiple nodes. <br> * SymbolSlider is a slider that allows users to set property values by dragging and includes a symbol. It can be used in scenarios such as adjusting screen brightness or volume, and it can customize the symbol display at the start of the slider. |
| [ListItem](/en_list-item) | ListItem is a general-purpose information display component for vertical lists and is often used as the content of Column or LazyColumn. |
| [TitleBar](/en_title-bar) | TitleBar is a title bar control that arranges user-defined styles in the left, center, and right sections of a single row, and provides two modes for centering the title content: absolute centering and relative centering. |
| [ProgressIndicator](/en_progress-indicator) | * LinearProgressIndicator is a basic linear progress indicator with determinate progress, composed of a background and a foreground. It is non-interactive and is commonly used in scenarios such as "loading content", "file upload", and more. <br> * CircularProgressIndicator is a basic circular progress control that is commonly used in scenarios such as loading content, file upload, and many other scenarios. <br> * SymbolicCircularProgressIndicator is a basic circular progress indicator commonly used in scenarios such as loading content, file upload, and other scenarios. It allows you to add custom icons to represent the current progress status. |
| [PageControl](/en_page-control) | * PageControl is a control that displays a series of horizontal dots to indicate page progress. <br> * ProgressPageControl is an extension of PageControl that assigns a progress value to each selected point. |
| [SegmentControl](/en_segment-control) | SegmentControl is a component used to switch between multiple mutually exclusive options. It typically consists of a series of icons or text options arranged side by side, allowing users to modify the display effect by clicking to select one of the options. |
| [SideNavigation](/en_side-navigation) | SideNavigation is a navigation control used for sidebars. It consists of a top title section and multiple sections, and is commonly used for navigation setup, sidebar menu partitioning, and similar scenarios. Structurally, it can be divided into a header and a navigation area. |
| [TextField](/en_text-field) | TextField is a component commonly used for text input. |
| [SearchField](/en_search-field) | SearchField allows users to enter text and trigger a search operation by pressing the search button on the keyboard or by other means. |
| [NumberField](/en_number-field) | NumberField allows users to create a numeric input box with increment and decrement buttons. |
| [TextSelectionAndToolbarProvider](/en_text-selection-and-toolbar-provider) | TextSelectionAndToolbarProvider provides configuration for text selection and toolbar colors, which is commonly used in scenarios such as changing the cursor or selection color in a TextField, or displaying a toolbar. |
| [Scroll Indicator](/en_scroll-indicator) | Scroll Indicator is typically used to visualize scroll progress on pages with long content, helping users perceive the length of the content and their current position, and improving navigation efficiency and user experience. |
| [Coachmark](/en_coachmark) | Coachmark is a component that displays content based on anchors. Coachmark consists of anchor points and content. CoachmarkBox provides the basic display of anchor points and, together with SimpleCoachmark, RichCoachmark, ImageCoachmark, and others, enables the final display of content. |
| [DatePicker](/en_date-picker) | * DatePicker is a control for selecting dates. <br> * DateRangePicker is a component for selecting a range of dates. |
| [TimePicker](/en_time-picker) | TimePicker is a control for selecting hours, minutes, and seconds. |
| [ToolBar](/en_tool-bar) | ToolBar is a type of container placed at the bottom center of the WindowContainer that can be used to display additional hint controls. |
| [TabBar](/en_tab-bar) | TabBar is a navigation control derived from the Augment container extension for system widgets, assisting users in switching between different modules within the application. |
| [AlertDialog](/en_alert-dialog) | An AlertDialog is a component used to interrupt users in order to prompt them, and can include an icon, a title, custom content, and buttons. |
| [Sheet](/en_sheet) | Sheet is a component used to present popup content and can handle tasks related to popups. |
| [Augment](/en_augment) | Augment is a container designed to be placed outside the main window and can be used to implement popup effects. |
| [Subwindow](/en_subwindow) | A Subwindow is a type of container displayed on the left or right side of a window container, and its height always matches that of the window container. |
| [Snack](/en_snack) | Snack is similar to Android Toast and can be used to display brief informational notifications at the bottom of WindowContainer. It is usually displayed for a few seconds before disappearing automatically. In addition to displaying the main information, it also provides interactive slots that allow customization of interactive behavior. |
| [Menu](/menu) | The menu component displays a list of selectable items as a floating window within the interface. The list content is typically used together with MenuItem, but it can also be fully customized. |
