Convert a color from the RGB color space to the HSV color space.

## Parameter description

* **In**: Input a color in standard RGB format.
* **Out**: Output a color vector containing hue (Hue), saturation (Saturation), and value (Value).

## Node usage instructions
This node performs a standard color space conversion algorithm, converting RGB values in the Cartesian coordinate system to HSV values in the cylindrical coordinate system. This enables more intuitive color adjustments, such as modifying hue or saturation independently.
