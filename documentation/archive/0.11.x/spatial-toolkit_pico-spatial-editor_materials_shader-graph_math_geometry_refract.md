Calculate the refracted vector based on the given surface normal and refractive index (eta).

## **Parameters**
Vectors passed to the **In** and **Normal** parameters must be normalized in advance.


* **In**: The vector to be refracted.
* **Normal**: The surface normal for refraction of the input vector.
* **Eta**: Refractive index.
