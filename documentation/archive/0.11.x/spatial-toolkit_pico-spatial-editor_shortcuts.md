This article introduces the shortcuts for Spatial Editor.
## General shortcuts
| **Function** | **macOS** | **Windows** | **Description** |
| --- | --- | --- | --- |
| Undo | Cmd + Z | Ctrl + Z | Undo the previous operation |
| Redo | Cmd + Shift + Z | Ctrl + Shift + Z | Redo the previous operation |
| Cut | Cmd + X | Ctrl + X | Cut |
| Copy | Cmd + C | Ctrl + C | Copy |
| Paste | Cmd + V | Ctrl + V | Paste |
| Duplicate | Cmd + D | Ctrl + D | Duplicate |
| Rename | Return | F2 | Rename |
| Delete | ⌫ | Delete | Delete |
| Frame Selected | F | F | Focus the camera on the selected object |
| Frame Scene | Cmd + F | Ctrl + F | Focus the camera on the current scene |
| Lock/Unlock | Cmd + L | Ctrl + L | Lock/Unlock; when locked, data cannot be modified |
| SelectAll | Cmd + A | Ctrl + A | Select all content in the current scene |
| Minimize Window | Cmd + M | Ctrl + M | Minimize the window |

## View window
### Toolbar
| **Shortcuts** | **Description** |
| --- | --- |
| Q | Move view |
| W | Move selected object |
| E | Rotate selected object |
| R | Scale selected object |
### Camera operations
| **Shortcuts** | Description |
| --- | --- |
| Right mouse button + Q | Move camera up |
| Right mouse button + W | Move camera forward |
| Right mouse button + S | Move camera backward |
| Right mouse button + E | Move camera down |
| Right mouse button + A | Move camera left |
| Right mouse button + D | Move camera right |
| Scroll mouse wheel | Move camera forward or backward |
| Hold and drag middle mouse button | Pan camera up, down, left, or right in space |
| alt/option + hold and move left mouse button | Orbit around the selected object |
| alt/option + hold and move right mouse button | Move camera forward or backward |
### Selection operations
| Shortcuts | Note |
| --- | --- |
| Shift + mouse click | Add the currently clicked object to the selection set |
| Ctrl + mouse click | Remove the currently clicked object from the selection set |
| Shift + box select | Add the currently box-selected object to the selection set |
| Ctrl + box select | Remove the currently box-selected object from the selection set |
