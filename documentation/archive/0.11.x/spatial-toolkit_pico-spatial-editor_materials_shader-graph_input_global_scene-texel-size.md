Provides information about the size of the current scene texture, as well as the normalized size corresponding to a single texel.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9ebb297aa7c441539fbd2a9f0f7be05b~tplv-goo7wpa0wc-image.image)
## Output description

* **Size**: The width and height of the scene texture.
* **TexelSize**: The size of a single texel in the texture coordinate space, typically equal to 1 / **Size**.
