This article guides you through the user interface of PICO Spatial Editor (Spatial Editor).
## Startup page
When you open Spatial Editor, the welcome page appears. On the welcome page, you can create a project, create a scene, or open an existing or recent project.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9e1a5b515dec4bebbba2a7d4574bd982~tplv-goo7wpa0wc-image.image)
## Spatial Editor main UI
After creating or opening a project, you can view and edit the project in Spatial Editor's main UI, and add or edit scenes within the project.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/42a163092b4f446e9c82e54c1c26123b~tplv-goo7wpa0wc-image.image)
## Scene tab bar
The scene tab bar is located below the title bar of the main interface in Spatial Editor and is used to manage scene tabs or create new scenes. The button on the right side of the scene tab bar can be used to open the Assets Library, making it easy to access resources needed for scene creation and editing.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0922a27282a1410fac69602c7c2ddb61~tplv-goo7wpa0wc-image.image)
The Assets Library includes several commonly used assets, such as models, materials, audio, special effects, and more. All assets must be downloaded online before they can be used. To add assets from the asset library to a scene, simply drag the asset into the scene's viewport window. You can also drag assets into the corresponding folder in the **Project Browser**.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/97ad0490d3404bd1b87a1d46c1c396c2~tplv-goo7wpa0wc-image.image)
## Viewport window
The viewport window is located at the center of the main interface in Spatial Editor and is used for editing and previewing scenes, such as selecting, moving, rotating, and scaling objects, and adjusting object perspectives.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6109b515f30f45a5a8e0833a3d722a1c~tplv-goo7wpa0wc-image.image)
## Hierarchy window
The **Hierarchy** window is on the left side of the main interface in Spatial Editor. The **Hierarchy** window displays the relationships between editable nodes in the scene using a tree view. Through the **Hierarchy** window, you can conveniently search for and edit nodes in the scene.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fd7039b3a30c48af9ee9cac68a3d83fa~tplv-goo7wpa0wc-image.image)
## Inspector window
The **Inspector** window is located on the right side of the main interface in Spatial Editor and is used to view and edit the components and component properties of the currently selected entity.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/dbbc58e3eb4a409f8ab2baa534e79806~tplv-goo7wpa0wc-image.image)
## Project Browser tab
The **Project Browser** tab is at the bottom of the main interface in Spatial Editor, displaying the project's folder structure in a tree format and automatically synchronizing changes made to the project folder contents in the operating system. Through the **Project Browser** tab, you can categorize, manage, add, delete, and preview project resources, enabling better organization of resources.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/47867339eeea4a0fa7f24e2e31604848~tplv-goo7wpa0wc-image.image)
## Shader Graph tab
**Shader Graph** tab is located at the bottom of the Spatial Editor main interface. In the **Shader Graph** tab, you can create custom shaders by creating and connecting nodes, without writing any code.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5c5eb69f01374de18d441741ab521a08~tplv-goo7wpa0wc-image.image)
## Timelines tab
**Timelines** tab is located at the bottom of the Spatial Editor main interface. In the **Timelines** tab, you can create 3D animations using preset animation templates without needing to understand the underlying animation production technologies.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e4d3b41e5d3240b6ae2db4c2ed996112~tplv-goo7wpa0wc-image.image)
## Audio Mixer tab
**Audio Mixer** tab is located at the bottom of the Spatial Editor main interface. In the **Audio Mixer** tab, you can create audio mix groups. You can use audio mix groups created in the audio mixer to uniformly adjust the playback properties of audio files, for example, mute, playback speed, and gain.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/51ae746c63754794a238e057cfdec48d~tplv-goo7wpa0wc-image.image)
## Statistics tab
**Statistics** tab is located at the bottom of the Spatial Editor main interface.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e2937eb6cb2b47b18c4652594a68aa26~tplv-goo7wpa0wc-image.image)
In the **Statistics** tab, you can view the following information:

* **General**: The number of entities in the scene.
* **Physics**: The number of entities in the scene with physics enabled, as well as the number of components such as Rigid Body and Collision.
* **Animation**: The number of entities in the scene with animation. Click the details button in the upper right corner of the **Animation** card to view the number of skeleton joints and animation joints.
* **Particles**: The number of particle components in the scene.
* **Materials**: The number of materials in the scene. Click the details button in the upper right corner of the **Materials** card to view usage details for each material.
* **Geometry**: The number of triangles, edges, and meshes in the scene. Click the details button in the upper right corner of the **Geometry** card to view the number of triangles for each entity and the memory usage of each mesh.
* **Lighting**: The number of lighting components in the scene.
* **Textures**: The number of materials in the scene and their memory usage. Click the details button in the upper right corner of the **Textures** card to view the resolution and memory usage of each material.

## Console tab
**Console** tab is located at the bottom of the Spatial Editor main interface and is used for real-time log output, helping you quickly locate and resolve issues encountered when editing and previewing 3D scenes.
