Logical OR operation on two Boolean values: **In 1** and **In 2**.

## Node usage
This node performs a logical OR operation. If at least one of **In 1** and **In 2** is True, the output is True; only when both are False, the output is False.
| **In 1** | **In 2** | **Out** |
| --- | --- | --- |
| True | True | True |
| True | False | True |
| False | True | True |
| False | False | False |
