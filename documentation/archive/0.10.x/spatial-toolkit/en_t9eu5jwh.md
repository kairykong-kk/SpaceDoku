The value of the specified mutable geometric property currently bound to the geometry (defined using MaterialX <geompropdef>).
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/01331f889f4644b19fc2b37fbf25fc38~tplv-goo7wpa0wc-image.image)
## Parameter description

* **Geomprop**: The name of the geometric property to read.
* **Default**: The value returned when the node cannot read the geometric property.
