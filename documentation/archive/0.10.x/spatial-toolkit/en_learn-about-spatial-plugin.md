PICO Spatial Plugin is an all-in-one spatial app development plugin based on Android Studio, providing developers with a complete toolchain for spatial app development.
PICO Spatial Plugin supports the following features:

* **Spatial app templates**: Provides templates for spatial apps in Android Studio. You can quickly create spatial projects based on the templates. For details, see [manage spatial projects](/manage-projects).
* **Build spatial projects**: Build spatial projects into spatial apps. For details, see [manage spatial projects](/manage-projects).
* **Manage spatial app development tools**: Install, upgrade, or uninstall PICO Emulator (emulator) and PICO Spatial Editor (Spatial Editor). For details, see [manage spatial app development tools](/manage-pico-toolbox).
* **Connect spatial apps to Spatial Editor**: You can import Spatial Editor projects into spatial projects to synchronously manage 3D resources and custom components in both Android Studio and Spatial Editor. For details, see [manage spatial projects](/manage-projects), [manage resources](/manage-resource), and [manage custom components](/use-custom-components).
