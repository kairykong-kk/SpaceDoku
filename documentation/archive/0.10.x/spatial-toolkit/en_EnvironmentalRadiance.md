Based on real-world environmental information and an IBL map (which can be provided by you or by using the default map), this node returns the environment's diffuse radiance value and specular radiance value.
**Environment Radiance** node itself does not directly receive IBL map input. IBL maps are typically provided by the scene environment, lighting system, or the project's default environment configuration. This node calculates and outputs the environment's diffuse radiance and specular radiance based on the current environment map and the input material parameters.

## Parameter description

* **Base Color**: The base display color of the surface, that is, the color the surface presents under pure white lighting.
* **Roughness**: The degree of surface roughness. The value ranges from 0 to 1.0. 0 indicates a fully specular surface, and 1.0 indicates maximum roughness. The default value is 0.
* **Specular**: The intensity of specular reflection on the surface, used to indicate the degree of specular reflection generated by the surface.
* **Metallic**: Used to indicate whether the surface has a metallic property. Set to 1 for metallic surfaces, and 0 for non-metallic surfaces. The default value is 0.0.
* **normal**: The surface normal vector. The default value is (0, 0, 0).

## Output description

* **diffuseRadiance**: The diffuse radiance of the surface, referring to the portion of light absorbed by the surface and then scattered in all directions.
* **specularRadiance**: The specular radiance of the surface, referring to the portion of light reflected from the surface.
