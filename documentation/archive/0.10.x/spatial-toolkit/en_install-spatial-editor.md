This article describes how to install PICO Spatial Editor.
## System requirements
### Operating system and hardware requirements
To use Spatial Editor, your operating system and hardware must meet at least the following minimum specifications.
| **Operating system** | **Requirements** |
| --- | --- |
| macOS <br>  <br>  | * **Operating system version**: macOS 14.0 <br> * **RAM**: 16 GB <br> * **Available disk space**: 32 GB <br> * **CPU**: M1 Pro (M2 Pro or above recommended), Intel chips are not supported |
| Windows | * **Operating system version**: Windows 10 64-bit or Windows 11 64-bit <br> * **RAM**: **** 16 GB <br> * **Available disk space**: 32 GB <br> * **CPU**: Intel Core i5 (Intel Core i7 or above recommended) or AMD Ryzen 5 1500X (AMD Ryzen 7 or above recommended) <br> * **GPU**: NVIDIA GTX 1060 (NVIDIA GTX 4070 or above recommended) or AMD Radeon RX 480 (AMD Radeon RX 7700 or above recommended) |
### Software requirements
PICO Spatial Plugin must already be installed. For details, see [Install PICO Spatial Plugin](/en_install-spatial-plugin).
## Steps
Install Spatial Editor through the PICO Spatial Plugin in Android Studio. For details, see [Manage spatial app development tools](/en_manage-pico-toolbox).
