This is used to return the floating-point value stored in the custom data of a `MeshInstancesResource` instance in the PICO Spatial SDK.
This node must be used with the PICO Spatial SDK. You need to create a `MeshInstancesResource` instance in the SDK.

## Parameter description

* **Index**: The custom data index of the `MeshInstancesResource` instance to be read.
