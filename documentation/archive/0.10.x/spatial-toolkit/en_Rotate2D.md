Rotate a 2D vector about the origin in two-dimensional space.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bd6e95be6e8543ceb5d7971f24c9b279~tplv-goo7wpa0wc-image.image)
## **Parameter description**

* **In**: The vector to be rotated.
* **Amount**: The rotation angle of the input vector, in degrees. A positive value indicates counterclockwise rotation; the default value is **0**.
