This article describes how to add and manage PICO Emulator in Android Studio.
PICO Emulator is a tool that simulates the PICO OS 6 environment on a PC. You can debug Spatial Apps in PICO Emulator. For details, see [What is PICO Emulator](/learn-about-pico-emulator).
## Prerequisites
To install and run PICO Emulator, your device must meet the following requirements:

* **Operating system and hardware requirements**: For details, refer to [Install PICO Emulator](/install-pico-emulator).
* **Software requirements**: Your device has PICO Spatial Plugin already installed. For details, refer to [Install PICO Spatial Plugin](/install-spatial-plugin).

## Procedure
### Step 1: Install PICO Emulator via PICO Spatial Plugin
After installing PICO Spatial Plugin, you can install PICO Emulator in Android Studio under **Settings...** > **Languages & Frameworks** > **PICO Spatial Tools**.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/adc7d982daa842be805a1491f32b5846~tplv-goo7wpa0wc-image.image)
### Step 2: Add PICO Emulator in Android Studio
Open your spatial project in Android Studio, click the plus sign in **Device Manager**, then select **Create PICO Emulator**.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ba06b02b1b0c4fb4954f24aa4a39cc10~tplv-goo7wpa0wc-image.image)
You can see the PICO Emulator you added in the device list of **Device Manager**.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a1c7fa9e587c44ffb4b84ad3ee27c8df~tplv-goo7wpa0wc-image.image)
### Step 3: Debug spatial projects in PICO Emulator
Ensure that the device displayed in the upper right corner of Android Studio is the PICO Emulator you added.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/90ef5bc763624a978e700309668107aa~tplv-goo7wpa0wc-image.image)
Select the module you want to run (such as app), then click the **Run** or **Debug** button in the upper right corner of Android Studio to compile your spatial project and install it in PICO Emulator for running and debugging.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/59e49e0cea0f4571b9b96adc915203a8~tplv-goo7wpa0wc-image.image)
