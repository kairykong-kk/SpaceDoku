Transform coordinates from one space to another.

## Parameter description

* **In:​**The coordinates to be transformed.
* **From Space:​**The source space where the input vector **In** is located. The default value is **world**. The following valid space values are available:
   * **model**: Local coordinate space relative to the model.
   * **object**: Coordinate space relative to the object.
   * **world**: Global coordinate space relative to the entire world.
* **To Space**: The target space to which the input vector **In** will be transformed. The default value is **world**. The following valid space values are available:
   * **model**: Local coordinate space relative to the model.
   * **object**: Coordinate space relative to the object.
   * **world**: Global coordinate space relative to the entire world.
