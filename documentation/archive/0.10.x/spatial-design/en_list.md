A list is an interactive component for displaying information and organizing information hierarchies. Lists efficiently display information and categorize data, thus providing effective guidance to users.
Information types displayed in the same list should be kept as uniform and consistent in layout as possible to help users quickly access information.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/855b25d203e1415ca4fd31f2ad675568~tplv-goo7wpa0wc-image.image)
## Anatomy
### List item
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e8ca241b605a49bf8aa6318e07607317~tplv-goo7wpa0wc-image.image)

1. Container: The size adapts to the content, and the visibility of the background color can be customized.
2. Leading element (optional): supports icons, images, or videos.
3. Title: Keep copies as clear and concise as possible to maintain text readability.
4. Trailing element (optional): Supports icon, text, text and icon, selection component, and more. Right alignment is recommended.
5. Subtext (optional): You can add multiple lines of supplementary explanatory text; it is recommended not to exceed three lines.
6. Supportive text (optional): Provides additional explanation for list item.

### Grouping
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/61f70e48df78447db91987e8ecd9f984~tplv-goo7wpa0wc-image.image)

1. Section: Paragraphs can have configurable titles
2. Grouping: Grouping is possible within the same paragraph. Separate each group with a space.
3. Separation: List items in the same group are separated by a 1dp divider.

## Interactive behavior
### Expand and collapse
The parent acts as a switch to manage the display of information for child items. This makes the information in the list more concise, making it easier for users to choose.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bf380d8ac48a4a1b8214af7c0c5e51e0~tplv-goo7wpa0wc-image.image)
### Drag and edit
List items are sorted by dragging. It also supports customizable editing lists.
