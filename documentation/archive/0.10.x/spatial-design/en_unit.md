## Spatial panel units

* The spatial panel uses units of dmm, while the Volumetric window and 3D model use meters.
* The design dimensions for the space panel use the dp unit, and the system automatically converts dp to dmm.

dmm (that is, distance-independent millimeter) is an angular unit that remains constant regardless of the distance between the user and the virtual object. dp (density-independent pixel) is a scalable unit that provides consistent sizing on any screen. They provide a flexible way to adapt to cross-platform design.

## Dynamic scaling
When the user moves the window application closer or farther, the spatial panel dynamically adjusts its scale to maintain a relatively constant field of view (FOV), ensuring that UI information on the interface can be clearly viewed and interacted with at different distances. However, the Volumetric window and 3D models do not change size.
