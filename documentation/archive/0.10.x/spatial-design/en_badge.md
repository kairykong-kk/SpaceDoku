Badge is used to indicate notifications, counts, or informational messages, to attract user attention and guide actions. Badge itself is not interactive, so it is usually placed inside other components, such as Tab Bar, Side Navigation, and so on.

## anatomy
### Label Badge
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7729dd48f70a4ba481d5c46ae16811e1~tplv-goo7wpa0wc-image.image)

1. Container: The container size automatically adapts to the content.
2. Text (optional): Try to keep the copy clear and concise to maintain readability.
3. Icon (optional)

The size of the Label Badge is relatively small; it is recommended to use strongly contrasting colors.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/07deb0432b054c58a972dfc44759c06a~tplv-goo7wpa0wc-image.image)
### Number Badge
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2c7bf93af4b14b3892985fa1db4ce754~tplv-goo7wpa0wc-image.image)

1. Container: The container size adjusts automatically to fit its content.
2. Number: Maximum value is set by the developer.
3. Ellipsis: When there are too many prompts, you can use an ellipsis.

Typically used to indicate unread messages. Although there is no restriction on the value of the number, the maximum character count must not exceed that of the parent container.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e48bbac7d1ff4f719f2e461726c6e56c~tplv-goo7wpa0wc-image.image)
### Dot Badge
The size of the style is fixed, and different meanings are assigned through color. The green Dot Badge at the bottom right of the friend's avatar, as shown above, indicates that the friend is online.
