High-definition UI rendering is a technology that shifts 2D interface rendering, which was previously performed by individual app processes, to unified UI rendering and composition by PICO OS 6 system services. This approach resolves the issue where the interface gradually becomes blurry as users approach an already opened 2D window.
**After enabling:**

* Provides users with high-definition text and vector graphics;
* Reduces the performance overhead of high-definition rendering;
* Assist in implementing features in Spatial UI, such as spatial floating.

High-definition UI rendering is currently in beta version. You can enable or disable the high-definition UI rendering for your apps in the developer options.
To experience the features of SpatialUI, you must keep high-definition UI rendering enabled.
