Output different results based on whether **Value1** is greater than or equal to **Value2**: if **Value1** >= **Value2**, output **True Result**; otherwise, output **False Result**.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/49ed53a2d2c9488db2bcf02694b858df~tplv-goo7wpa0wc-image.image)
## Parameter description

* **Value1**: The first value to compare.
* **Value2**: The second value to compare.
* **True Result**: The result output when **Value1** is greater than or equal to **Value2**.
* **False Result**: The result output when **Value1** is less than **Value2**.
