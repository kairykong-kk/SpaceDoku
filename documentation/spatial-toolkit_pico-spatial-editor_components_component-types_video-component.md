This article introduces the video component in Spatial Editor.
## Video
You can use 2D or 3D video as the texture of a video material, mapping it onto the surface of a created 3D model to achieve the effect of playing video on the object's surface.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4213d97787014dcd9d13b992d053e286~tplv-goo7wpa0wc-image.image)
| **Parameters** |  | **Note** |
| --- | --- | --- |
| **Mesh** |  | Specify the mesh used to display video content. The video frame will be rendered onto the surface of the selected mesh. |
| **Texture Sample Mode** |  | Specify the sampling mode for the video texture. <br>  <br> * **None:** No texture sampling is performed; the video texture will be displayed in its original state without any additional processing. <br> * **Raw:** Uses the raw texture sampling mode; the video texture will be displayed in a form closest to the original data, preserving the video's details and color information to the greatest extent. <br> * **Blurred:** Uses the blurred texture sampling mode; the video texture will be processed with a blur effect, which can be used to create soft and hazy visual effects. |
| **Texture Sample Name** |  | Specify the texture sampling name. This needs to correspond to the texture property name defined in the material or Shader. |
| **Display Mode** |  | Specify the display mode for the video content. <br>  <br> * **None**: The display mode of the video is determined by the **Dimension Mode** parameter. <br> * **Mono**: The video is presented in a single view without stereoscopic effect, suitable for standard 2D videos or video content that does not require stereoscopic display. <br> * **Stereo**: The video is presented in a stereoscopic view with a stereoscopic effect, suitable for 3D source videos containing binocular disparity, such as side-by-side, top-and-bottom layouts, and MV - HEVC 3D format videos. |
| **Video Material** | **Blending Mode** | Specify the blending mode for the video material. <br>  <br> * **Opaque**: The video material uses opaque blending. <br> * **Transparent**: The video material uses transparent blending. |
|  | **Face Culling** | Specify the face culling mode, such as back-face or front-face culling. <br>  <br> * **None**: No face culling is performed; all faces are displayed. <br> * **Front**: The front face is culled; only the back face is displayed, and the front face is hidden. <br> * **Back**: The back face is culled; only the front face is displayed, and the back face is hidden. |
|  | **Dimension Mode** | Specify the dimension mode for the video. <br>  <br> * **Mono**: The video is presented in a single view without stereoscopic effect, suitable for standard 2D videos or video content that does not require stereoscopic display. <br> * **TopDown**: The video is presented in a dual-view format with top and bottom views, typically used for stereoscopic videos. The top and bottom views correspond to the left and right eye images, providing users with a stereoscopic visual experience. <br> * **SideBySide**: The video is presented in a dual-view format with left and right views, commonly used for stereoscopic videos. The left and right views correspond to the left and right eye images, allowing users to experience a stereoscopic visual effect. <br> * **MultipleView**: The video is presented in a multi-view format, displaying multiple perspectives simultaneously. This is suitable for complex video scenarios that require multi-angle observation and provides users with richer visual information. |
|  | **Color** | Specify the color of the video material. Can be used to adjust the overall color of the video display. |
|  | **Shader Graph Material** | Specify the Shader Graph material used for video rendering. Once set, custom material effects can be used to present video content. |
| **Preview** | **Video File** | Specify the video file for preview, used to preview the video display effect in the Spatial Editor. |
