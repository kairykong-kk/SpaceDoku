Map the input value from one range to another using a linear method.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c61a4826bfb347709a88357eae1f2933~tplv-goo7wpa0wc-image.image)
## Parameter description

* **In**: The original input value to be remapped.
* **In Low**: The starting point of the input value range.
* **In High**: The end point of the input value range.
* **Out Low**: The starting point of the output value range.
* **Out High**: The end point of the output value range.
