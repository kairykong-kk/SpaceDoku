Outputs different results depending on whether **Value1** is greater than **Value2**: if **Value1** > **Value2**, outputs **True Result**; otherwise, outputs **False Result**.

## Parameter description

* **Value1**: The first value to compare.
* **Value2**: The second value to compare.
* **True Result**: The result output when **Value1** is greater than **Value2**.
* **False Result**: The result output when **Value1** is not greater than **Value2**.
