Timelines is an animation effects tool provided by Spatial Editor. With Timelines, you can add animation effects to entities using preset animation templates without needing to understand the underlying animation production technologies.
The Timelines animation effects tool is currently in Beta testing. Please provide feedback promptly if you encounter any issues.
