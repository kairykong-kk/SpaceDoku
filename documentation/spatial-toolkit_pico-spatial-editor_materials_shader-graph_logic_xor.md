Logical exclusive OR (XOR) operation between two Boolean values, **In1** and **In2**.

## Node usage instructions
This node performs a logical exclusive OR (XOR) operation. When the values of **In 1** and **In 2** are different, the output is True; when both values are the same, the output is False.
| **In 1** | **In2** | **Out** |
| --- | --- | --- |
| True | True | False |
| True | False | True |
| False | True | True |
| False | False | False |
