The logical AND operation between two Boolean values, **In 1** and **In2**.
![Image](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b356303f408741daa4a977e90474258d~tplv-goo7wpa0wc-image.image)
## Node usage instructions
This node performs a logical AND operation. The output is True only when both **In 1** and **In2** are True; otherwise, the output is False.
| **In 1** | **In 2** | **Out** |
| --- | --- | --- |
| True | True | True |
| True | False | False |
| False | True | False |
| False | False | False |
